| Primary Dark | `#1D4ED8` | 按钮按下态 |
| Success | `#10B981` | 审核通过、成功提示 |
| Warning | `#F59E0B` | 审核中、警告提示 |
| Danger | `#EF4444` | 审核拒绝、错误提示、删除操作 |
| Text Primary | `#1F2937` | 主标题、正文 |
| Text Secondary | `#6B7280` | 副标题、辅助说明、占位文字 |
| Text Tertiary | `#9CA3AF` | 时间戳、禁用态文字 |

### 2.2 字体规范

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 20px | 600 | 28px | 页面大标题、角色名 |
| H2 | 18px | 600 | 26px | 模块标题、卡片标题 |
| H3 | 16px | 500 | 24px | 列表项标题、表单标签 |
| Body | 14px | 400 | 22px | 正文、描述文字 |
| Caption | 12px | 400 | 18px | 辅助说明、时间戳、标签 |
| Small | 11px | 400 | 16px | 角标、极次要信息 |

### 2.3 间距体系（4px 基准）

| Token | 值 | 用途 |
|-------|-----|------|
| space-xs | 4px | 图标与文字间距、紧密元素 |
| space-sm | 8px | 行内元素间距、标签间距 |
| space-md | 12px | 卡片内边距、表单元素间距 |
| space-lg | 16px | 模块间距、列表项内边距 |
| space-xl | 20px | 区块间距、页面水平边距 |
| space-2xl | 24px | 大区块间距、按钮组间距 |
| space-3xl | 32px | 页面顶部安全区、大模块间距 |

### 2.4 圆角与阴影

| Token | 值 | 用途 |
|-------|-----|------|
| radius-sm | 4px | 标签、小按钮 |
| radius-md | 8px | 输入框、列表项 |
| radius-lg | 12px | 卡片、面板、大按钮 |
| radius-xl | 16px | 底部弹窗、模态框 |
| radius-full | 999px | 圆形头像、状态标签 |
| shadow-sm | `0 1px 2px rgba(0,0,0,0.05)` | 卡片默认态 |
| shadow-md | `0 4px 6px rgba(0,0,0,0.07)` | 浮层、下拉面板 |
| shadow-lg | `0 10px 15px rgba(0,0,0,0.1)` | 底部弹窗、模态框 |

## 三、全局交互规范

### 3.1 页面转场
- 页面跳转：微信小程序默认 `navigateTo` 滑动转场
- 返回：左滑返回或点击导航栏返回按钮
- 底部弹窗：`showModal` / 自定义底部弹窗，从底部向上滑入

### 3.2 加载策略（全局强制）

| 场景 | 加载方式 | 说明 |
|------|----------|------|
| 页面首次进入 | 全页 Skeleton | 顶部导航以下区域全部被 Skeleton 覆盖 |
| 列表数据加载 | 列表 Skeleton + 分页加载 | 首屏 10 条用 Skeleton 占位，触底加载更多显示底部加载动画 |
| 图片加载 | 图片 Skeleton | 图片区域显示灰色占位块，加载完成后淡入显示（opacity 0 -> 1，300ms） |
| 下拉刷新 | 顶部加载动画 + 数据重载 | 触发后列表顶部显示旋转加载图标，数据回来后 Skeleton 替换为真实内容 |
| 操作提交 | 按钮 Loading 态 | 按钮文字替换为"提交中..."，禁用点击，显示加载图标 |

### 3.3 空状态与错误状态
- 空状态：居中图标（空盒子插画 120x120）+ 标题"暂无数据" + 辅助说明 + 可选刷新按钮
- 网络错误：居中图标（断网插画 120x120）+ 标题"网络开小差了" + 按钮"重新加载"
- 权限拒绝：居中图标 + 标题"需要授权" + 按钮"去设置"

### 3.4 Toast 提示
- 成功：`wx.showToast({ icon: 'success', title })`，2 秒自动消失
- 失败：`wx.showToast({ icon: 'error', title })`，2 秒自动消失
- 加载中：`wx.showLoading({ title: '加载中' })`，操作完成后手动 `hideLoading`

## 四、组件规范

### 4.1 顶部导航栏（自定义或系统）
- 优先使用微信小程序原生导航栏
- 需要自定义时：高度 44px + 状态栏高度，背景色白色 `#FFFFFF`，底部 1px `Border` 分割线
- 标题居中，H2 字号，`Text Primary` 色
- 左侧返回按钮：24x24px 箭头图标

### 4.2 按钮 Button

| 类型 | 背景 | 文字 | 圆角 | 高度 | 禁用态 |
|------|------|------|------|------|--------|
| Primary | `#2563EB` | `#FFFFFF` 16px 500 | radius-lg | 48px | 背景 `#93C5FD`，文字 `#FFFFFF` |
| Secondary | `#DBEAFE` | `#2563EB` 16px 500 | radius-lg | 48px | 背景 `#EFF6FF`，文字 `#93C5FD` |
| Ghost | 透明 | `#2563EB` 14px 400 | radius-md | 40px | 文字 `#93C5FD` |
| Danger | `#EF4444` | `#FFFFFF` 16px 500 | radius-lg | 48px | 背景 `#FCA5A5` |
| Text Link | 透明 | `#2563EB` 14px 400 | - | auto | 文字 `#93C5FD` |

- 按钮点击态：透明度降低到 0.85
- 全宽按钮：左右 margin space-xl

### 4.3 输入框 Input

| 状态 | 边框 | 背景 | 说明 |
|------|------|------|------|
| 默认 | 1px `#E5E7EB` | `#FFFFFF` | - |
| 聚焦 | 1px `#2563EB` | `#FFFFFF` | 边框变主色 |
| 错误 | 1px `#EF4444` | `#FEF2F2` | 下方显示红色错误提示文字 |
| 禁用 | 1px `#E5E7EB` | `#F3F4F6` | 文字色 `#9CA3AF` |

- 高度 48px，内边距左右 space-lg，圆角 radius-md
- 标签在输入框上方，H3 字号，`Text Primary`
- 必填项标签后带红色星号 `*`
- 验证码输入：右侧内嵌"获取验证码"文字按钮，倒计时 60s 变灰禁用

### 4.4 卡片 Card
- 背景 `#FFFFFF`，圆角 radius-lg，内边距 space-lg
- 阴影 shadow-sm（可选，列表卡片不加阴影，功能面板加）
- 卡片标题区：左标题（H3）+ 右操作（Text Link），标题下方可选 1px 分割线

### 4.5 列表项 List Item
- 高度自适应，最小 72px
- 左侧：头像/图标（48x48px，radius-md 圆角）或纯文字序号
- 中间：主标题（H3）+ 副标题（Caption，`Text Secondary`）
- 右侧：箭头图标（16x16px，`Text Tertiary`）或状态标签
- 底部 1px `Border` 分割线（最后一项无）
- 点击态：背景变 `#F3F4F6`

### 4.6 状态标签 Tag

| 状态 | 背景 | 文字 | 圆角 |
|------|------|------|------|
| 审核中 | `#FEF3C7` | `#D97706` | radius-full |
| 已通过 | `#D1FAE5` | `#059669` | radius-full |
| 已拒绝 | `#FEE2E2` | `#DC2626` | radius-full |
| 企业客户 | `#DBEAFE` | `#2563EB` | radius-full |
| 银行人员 | `#E0E7FF` | `#4F46E5` | radius-full |
| 业务员 | `#F3E8FF` | `#7C3AED` | radius-full |

- 标签高度 22px，水平内边距 8px，字号 Caption

### 4.7 Skeleton 骨架屏组件（全局强制）

#### 4.7.1 列表骨架屏 `SkeletonList`
- 5-8 个列表项占位，循环展示
- 每个项：左侧圆形占位 48x48（`Skeleton Base`）+ 右侧两行文字占位（第一行 60% 宽度，第二行 40% 宽度）
- 动画：从左到右的闪光扫过效果（`Skeleton Shine` 到透明再回 `Skeleton Base`，1.5s 循环）

#### 4.7.2 卡片骨架屏 `SkeletonCard`
- 顶部图片占位：宽度 100%，高度 160px，radius-lg 顶部圆角
- 标题占位：宽度 70%，高度 16px，margin-top 12px
- 描述占位：宽度 90%，高度 14px，margin-top 8px
- 描述第二行：宽度 60%，高度 14px，margin-top 8px

#### 4.7.3 页面骨架屏 `SkeletonPage`
- 顶部：导航栏正常显示（不骨架化）
- 下方：根据页面类型组合 `SkeletonList`、`SkeletonCard`、表单占位块
- 表单占位：标签短条（40px 宽）+ 输入框长条（100% 宽，48px 高），间隔 16px

#### 4.7.4 图片骨架屏 `SkeletonImage`
- 纯灰色占位块，圆角与目标图片一致
- 动画同上，加载完成后目标图片淡入（opacity 0->1，300ms）覆盖骨架屏

### 4.8 上传组件 Upload（含参考图）
- 上传区域：虚线边框（1px dashed `#E5E7EB`），圆角 radius-lg，背景 `#FAFAFA`
- 区域内居中：上传图标（32px，`Text Tertiary`）+ "点击上传" 文字（Caption）
- 参考图入口：上传区域右上角小图标（眼睛图标），点击弹出大图预览
- 已上传：显示缩略图（80x80，radius-md），右上角删除按钮（红色圆形 X）
- 多文件：水平滚动排列

## 七、Skeleton 骨架屏全页面覆盖清单

| 页面 | Skeleton 类型 | 覆盖区域 |
|------|--------------|----------|
| 启动页/角色选择 | 无 | 本地静态资源，无需骨架 |
| 登录页 | 无 | 静态表单 |
| 注册页 | SkeletonPage | 表单区域（ dim_data_config 参考图弹窗用 SkeletonImage） |
| 忘记密码 | 无 | 静态表单 |
| 协议页 | SkeletonImage（如有图片） | 纯文字无 Skeleton |
| 首页（企业） | SkeletonCard + SkeletonList | Banner 轮播区、推荐人员横向列表 |
| 首页（银行/业务） | SkeletonCard | 数据概览卡片、最近浏览列表 |
| 银行人员列表 | SkeletonList | 全部列表项 |
| 银行人员详情 | SkeletonCard + SkeletonImage | 头像、信息卡片各区块 |
| 聊天页 | 无 | 本地存储优先加载 |
| 网点查询（列表） | SkeletonList | 网点列表 |
| 网点查询（地图） | SkeletonImage（全屏灰底） | 地图加载前全屏占位 |
| 网点详情 | SkeletonImage | 地图预览区 |
| 企业客户列表 | SkeletonList | 客户列表 |
| 企业客户详情 | SkeletonCard + SkeletonImage | 信息卡片、附件缩略图 |
| 个人中心 | SkeletonCard | 头部信息区（头像、名称） |

## 八、设计原则总结

1. **一致性**：所有按钮、输入框、卡片、标签严格遵循本规范，禁止随意调整尺寸和颜色。
2. **可读性**：金融类信息需要极高的可读性，正文最小 14px，对比度符合 WCAG AA 标准。
3. **可信赖**：蓝色主色调传递专业、可信赖的品牌感知，避免使用过于活泼的颜色。
4. **性能感知**：Skeleton 骨架屏让用户感知到"内容正在赶来"，减少等待焦虑，所有异步数据区域必须有 Skeleton。
5. **触控友好**：按钮最小触控区域 44x44px，列表项最小高度 72px，表单元素间距充足，避免误触。
